A vector editor in the browser. AI agents draw on it through MCP, and you edit the same document on an Illustrator-style canvas.

An agent drew this wordmark. The selection is yours now: drag an anchor or a handle, and hold Alt on a handle to make a corner.

Artboard 2

Editable vectors, not pictures

Whatever an agent makes stays as paths, shapes and text. Pick any of it up and keep working by hand.

  • Charts and diagrams

    From data or a Mermaid description, drawn as shapes you can select, restyle and move.

  • Illustration, icons and logos

    Bezier paths, compound shapes that stay live, gradients and a stack of fills and strokes.

  • Freehand drawing

    Strokes that follow pen pressure, fitted to smooth curves with a few anchors to adjust.

Artboard 3

Not ready to use yet

Kalamo is being built in the open, one milestone at a time. The foundation works: an agent draws over MCP and the browser shows it live. The drawing tools, type, charts and hosting are being built now.

  1. Foundation Done

    The document model, undo, the MCP server and a live browser viewer.

  2. First release In progress

    Pen and Pathfinder, type, charts, SVG round trips with Inkscape, and hosting.

  3. Freehand and illustration

    Pressure strokes, brushes, effects, symbols and blends.

  4. Speed and collaboration

    GPU rendering, several people and agents at once, and version history.

Open source under Apache-2.0. Kalamo comes from the Greek kálamos, the reed pen. The same word still means “pen” as Arabic qalam, Turkish kalem and Swahili kalamu.
